# 5-step picture guide (no GitHub)

1. Unzip `forge-starter` to your Desktop.
2. Open Terminal / Command Prompt.
3. `cd` into the folder (e.g. `cd ~/Desktop/forge-starter`).
4. `python3 -m pip install -r requirements.txt`
5. `bash scripts/run_pipeline.sh 10`

You will see leads and draft proposals in `data/`. Nothing sends until you opt in.
